📚 数据分析技术知识点学习

一、数据分析概述

1.1 数据分析的定义
数据分析是用适当的统计分析方法对收集来的大量数据进行分析，将它们加以汇总和理解并消化，以求最大化地开发数据的功能，发挥数据的作用。数据分析是为了提取有用信息和形成结论而对数据加以详细研究和概括总结的过程。
基础概念
1.2 数据分析的基本流程
1. 明确分析目的：确定要解决什么问题
2. 数据收集：通过爬虫、API、数据库等方式获取数据
3. 数据清洗：处理缺失值、异常值、重复值
4. 数据分析：使用统计方法进行数据分析
5. 数据可视化：通过图表展示分析结果
6. 报告撰写：总结结论并提出建议
流程
1.3 数据分析的工具
Python生态系统：
• NumPy：数值计算基础库
• Pandas：数据处理和分析
• Matplotlib/Seaborn：数据可视化
• Scikit-learn：机器学习

其他工具：
• Excel：基础数据分析
• SQL：数据库查询
• Tableau：商业智能可视化
工具

二、数据清洗

2.1 缺失值处理
缺失值类型：完全随机缺失、随机缺失、非随机缺失

处理方法：
• 删除法：删除缺失值所在的行或列
• 均值填充：用均值填充数值型缺失值
• 中位数填充：用中位数填充，避免异常值影响
• 众数填充：用于分类变量
• 插值法：使用前后值进行插值
• 模型预测：用其他特征预测缺失值
重要
2.2 异常值检测
异常值定义：偏离大部分数据分布的点

检测方法：
• 3σ原则：数据落在(μ-3σ, μ+3σ)区间外的概率为0.27%
• IQR四分位距：小于Q1-1.5×IQR或大于Q3+1.5×IQR为异常
• 散点图：可视化观察离群点
• Z-score：标准化后绝对值大于3的为异常

处理方式：删除、替换为边界值、或保留并标记
重要
2.3 数据类型转换
常见数据类型：
• 数值型：int, float
• 字符串型：str
• 日期时间型：datetime
• 类别型：category, object

转换方法：
• pd.to_numeric()：转换为数值型
• pd.to_datetime()：转换为日期时间
• astype()：强制类型转换
• apply()：使用自定义函数转换
技巧

三、数据可视化

3.1 常用图表类型
比较类：
• 柱状图：比较不同类别的数值大小
• 折线图：展示数据随时间变化的趋势
• 雷达图：多维度对比

构成类：
• 饼图：展示各部分占比
• 堆叠柱状图：展示整体和部分关系

分布类：
• 直方图：展示数据分布
• 箱线图：展示统计特征和异常值
• 散点图：展示两个变量关系
可视化
3.2 Python可视化库
Matplotlib：最基础的绑图库，灵活性高但语法较复杂

Seaborn：基于Matplotlib，语法简洁，默认样式美观

Plotly：支持交互式图表，适合Web展示

Pandas：集成了基础的plot方法，适合快速绑图
工具

四、统计分析基础

4.1 描述性统计
集中趋势：
• 均值(Mean)：数据的算术平均值
• 中位数(Median)：排序后位于中间的值
• 众数(Mode)：出现次数最多的值

离散程度：
• 方差(Variance)：数据偏离均值的程度
• 标准差(Std)：方差的平方根
• 极差(Range)：最大值与最小值之差
• 四分位距(IQR)：Q3与Q1之差
统计
4.2 相关性分析
Pearson相关系数：衡量两个连续变量之间的线性关系
范围：-1到1，接近1表示强正相关，接近-1表示强负相关

Spearman相关系数：衡量单调关系，不要求线性

相关系数解读：
• |r| < 0.3：弱相关
• 0.3 ≤ |r| < 0.7：中等相关
• |r| ≥ 0.7：强相关
